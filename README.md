# To-Do List App - React.js

Aplikasi To-Do List frontend yang dibuat menggunakan React.js (Vite). Aplikasi ini menggunakan data dummy dan state management `useState` untuk mensimulasikan operasi CRUD (Create, Read, Update, Delete).

## Fitur
- Menampilkan daftar tugas.
- Melihat detail tugas.
- Menambahkan tugas baru (form).
- Memperbarui tugas yang ada (form edit).
- Menghapus tugas (dengan konfirmasi peringatan).
- Menggunakan React State untuk memperbarui UI tanpa reload.

## Cara Menjalankan
1. Clone repository ini.
2. Jalankan `npm install`.
3. Jalankan `npm run dev`.
4. Buka `http://localhost:5173` di browser.
